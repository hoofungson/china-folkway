## 一、概述

平昌民间把**婚礼、寿诞、生育、乔迁**等喜庆称作「**红事**」，把**丧事**称作「**白事**」，合称「**红白喜事**」。本地重「**人情**」，礼尚往来是邻里、亲属维系关系的核心；红白喜事皆讲究**择吉日、请亲戚、设宴款待、随礼往来**。

> 本地口传：川东北有「**红事请，白事到**」之说——红事（婚礼、寿宴等）须主人**发请柬/相邀**才去；白事则亲友**主动上门**吊唁帮忙。各地细节以当地长辈和家族惯例为准。

## 二、婚嫁礼俗（红事）

### 2.1 流程总览

| 阶段 | 说明 |
| --- | --- |
| 提亲 / 说媒 | 由媒人牵线，两家议亲 |
| 合八字 / 看日子 | 请人合八字，择定婚期（良辰吉日） |
| 定亲 / 订婚 | 下聘、交换庚帖，两家确定婚事 |
| 过礼 / 送彩礼 | 男方送彩礼（聘礼），女方回礼 |
| 迎亲 | 新郎带迎亲队伍至女方家接亲 |
| 拜堂 | 拜天地、拜高堂、夫妻对拜 |
| 闹新房 | 亲友闹洞房，增添喜庆 |
| 回门 / 谢媒 | 三朝回门，婚后谢媒、走亲戚 |

### 2.2 本地特色

- **接亲车队/队伍**：川东北婚庆近年多用车队，农村有些保留抬花轿、举伞等旧俗。
- **哭嫁 / 骂媒**：部分地方有「哭嫁」旧俗（新娘哭诉离别），现已少见，以当地口传为准。
- **讨红包**（接亲时）：迎亲队伍进门，女方亲友讨「红包」「开门礼」，增添喜庆。
- **闹新房**：亲友闹洞房，以「越闹越热闹」为吉。
- **三日回门**：婚后第三天（或选日）新娘新郎回娘家「回门」，答谢父母养育。

### 2.3 婚宴与随礼
- 婚宴设「**喜宴**」，宴请亲友；多用**红色**（喜气）。
- 亲友随礼（**贺仪**），写礼金封皮（见第七章「贺仪」）。

## 三、生育礼俗（三朝 / 满月 / 周岁）

### 3.1 三朝 / 打三朝

- **时间**：婴儿出生后第三天（三朝），举行「三朝礼」。
- **习俗**：
  - **洗三**：给婴儿洗澡（洗三朝），寓意洗去秽气、祝健康。
  - **报喜**：向亲友报喜。
  - 男孩称「**弄璋之喜**」、女孩称「**弄瓦之喜**」（见烧袱子指南 4.6 节「弄璋之期 / 弄瓦之期」）。
- **送礼**：亲友送鸡蛋、红糖、衣物等（「**贺生**」）。

### 3.2 满月

- **满月酒**：婴儿满月办酒席宴请亲友（「满月宴」）。
- 亲友送**长命锁、银饰、红包**等；外婆家送衣物、银饰（「**送满月**」）。

### 3.3 周岁（抓周）

- **周岁宴**：办周岁酒，举行「**抓周**」——摆书、笔、算盘、钱、玩具等，任婴儿抓取，预测将来志向（民间趣味，理性看待）。

## 四、寿诞礼俗

| 对象 | 称呼 | 说明 |
| --- | --- | --- |
| 长辈寿辰 | 做寿 | 逢整十（六十、七十、八十）重大寿 |
| 满月 / 周岁 | 生日 | 见第三章 |
| 高寿 | 敬老 | 近年重「敬老」 |

- **做寿**：设寿宴，亲友祝寿送礼（**寿敬**，见第七章）；点寿烛、吃寿面（长寿面）、寿桃。
- **本地注**：川东北做寿**六十为大寿**，送「寿敬」礼金；丧事送礼称「香仪」（见第六章）。

## 五、乔迁与建房礼俗

| 事项 | 说明 |
| --- | --- |
| 上梁 | 建房架梁，择吉「**上梁**」，请匠人，亲友帮忙，挂红、放炮（「**竣工**」「竖造」之期） |
| 乔迁（进新房） | 择吉搬迁，设「**乔迁宴**」，亲友送礼（「**乔迁**」/「菲仪」） |
| 敬土地 / 安宅 | 迁居前后敬土地神、安宅（见《平昌祭祀与丧葬礼俗》「家宅神祇」） |

- 乔迁宴多用红色，寓意「**乔迁之喜**」；送礼封皮写「**乔迁**」或「**菲仪**」（见第七章）。

## 六、白事人情往来（香仪 / 随礼）

> 白事全程礼仪详见《平昌祭祀与丧葬礼俗》v1.0.0。本节侧重**人情往来**。

- **主动到场**：白事亲友**主动上门**吊唁、帮忙（川东北「白事到」），无需请柬。
- **送礼（香仪 / 冥仪）**：亲友送「**香仪**」（丧事礼金，也叫「人情」「奠仪」），封皮写「**香仪**」。
- **随礼数额**：礼金多寡视亲疏与家境，川东北多以「回礼」方式体现人情（主家回赠，如回礼布、回礼钱）。
- **吊唁**：送花圈、挽联、孝帕；拜灵、上香、鞠躬（或跪拜）。

> 烧袱子 / 化纸涉及的**期语**（除灵、葬期、忌日、周年等）及**随礼称呼**（香仪、贺仪、寿敬、乔迁等）见《平昌七月半烧袱子书写指南》4.6 节「送礼仪语」。

## 七、礼金封皮与随礼称呼

> 送礼时礼金封皮（信封/红包）常用红色（红事）或白色（白事），其上书写随礼称呼。以下称呼与烧袱子指南 4.6 节「送礼仪语」一致。

| 场合 | 封皮称呼 | 备注 |
| --- | --- | --- |
| 送男方结婚 | 贺仪 | 红事 |
| 送女方出阁 | 奁仪 | 红事 |
| 祝寿送礼 | 寿敬 | 红事 |
| 建房迁居 | 乔迁（或菲仪） | 红事 |
| 饯行送礼 | 展翅（或文仪） | 红事 |
| 丧事送礼 | 香仪 | 白事 |
| 生育送礼 | 贺生（或弄璋 / 弄瓦之仪） | 红事 |

> 随礼与礼节因亲疏、家境而异，以当地习惯与主家约定为准。

## 八、红白喜事禁忌与讲究

> 川东北民间传统说法，供参考；现代家庭不必过度拘泥。

- **红事请、白事到**：红事邀约，白事主动（见第一章）。
- **丧期避喜**：家有新亡，短期内不宜办红事；喜事、白事宜错开。
- **红色 / 白色**：红事用红色（喜气），白事用白色（哀思），不宜混用。
- **红事忌带孝**：家有孝服（守孝）者，部分人家避参加红事（旧俗）。
- **吉日选择**：婚、寿、乔迁多择「**吉日**」（请人看日子），避开「杨公忌日」等不吉之日（各地不一）。
- **白事帮忙重「孝」**：帮忙者、亲友丧期行为从容得体，忌嬉闹（喜丧例外）。
