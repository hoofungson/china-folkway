## 一、概述

平昌及川东北的祭祀与丧葬，核心是「**敬天法祖、慎终追远**」。祭祀分**家宅祭祀**（灶神、土地、门神、财神、祖先）与**祠墓祭祀**（上坟、立碑、扫墓、烧袱子）；丧葬则以「**送亡人最后一程**」为要，讲究程序、孝道与厚葬。

> 本地口传：平昌丧葬重「**孝**」与「**礼**」，流程多而繁，但以「**让亡人走得体面、让后人心里安宁**」为本。各地具体规矩差异较大，以当地长辈、阴阳先生（地理先生）和家族惯例为准。

## 二、祭祀的基本对象与分类

| 分类 | 对象 | 常见时机 | 主要形式 |
| --- | --- | --- | --- |
| 家宅神祇 | 灶神 | 腊月小年、日常 | 供灶、祭灶 |
| 家宅神祇 | 土地 / 地盘业主 | 建房、迁居、祭祀 | 烧纸、供土地（见烧袱子「地盘业主」） |
| 家宅神祇 | 门神、财神 | 春节 | 贴门神、接财神 |
| 祖先祭祀 | 祖先（考妣/祖辈） | 春节、清明、七月半、寒衣节、忌日 | 烧袱子、上坟、供饭 |
| 祖先祭祀 | 新亡者 | 七七、百日、周年、三年 | 烧袱子、化纸、除灵 |
| 神鬼祭祀 | 孤魂野鬼（外财） | 七月半 | 圈外烧纸、布施（见烧袱子「孤魂外财」） |
| 特殊祭祀 | 车夫力士 | 七月半 | 烧脚力钱（见烧袱子「车夫力士」） |

**说明：** 平昌民间祭祀注重「**先祭神、后祭祖**」——正式祭祖前，常先化纸敬土地（地盘业主）与车夫力士，寓意「打个招呼、托人带路」，以免先祖钱财被截。

## 三、祭祀用品与祭供

| 用品 | 用途与说明 |
| --- | --- |
| 纸钱 / 冥币 / 金银锭 | 化纸、烧包袱用 |
| 钱凿 | 在草纸上打铜钱印（打纸钱） |
| 香、烛 | 上香、点烛 |
| 纸扎（纸衣、纸屋、纸马） | 烧给亡人（寒衣、冥屋等） |
| 供品 | 刀头肉、整鸡、酒、水果、点心、米饭 |
| 奠酒 / 水饭 | 祭奠、送祖时泼洒 |
| 花圈、挽联、白布 | 丧仪用 |
| 长明灯 / 灵前灯 | 守灵时点 |
| 草木灰 | 烧纸画圈用 |

**祭供（摆供）讲究：**
- 供桌置于堂屋或墓前，讲究「**上香三炷、点烛一对、摆供按辈分**」。
- 供品中刀头肉、酒为必备（「刀头」即整块熟猪肉，象征敬意）。
- 祭供后要「**撤供**」，供品可分食或收回，不随意丢弃。

## 四、丧葬全程礼仪（白事）

### 4.1 临终与初丧

| 步骤 | 说明 |
| --- | --- |
| 送终 | 亲人守在床前，送亡人最后一程；讲究「断气前赶到」 |
| 烧倒头纸/落气纸 | 亡人落气后，烧纸钱（倒头纸/落气纸），口念送行 |
| 沐浴更衣 | 给亡人擦身、穿寿衣（「装老衣」，件数讲究三、五、七） |
| 报丧 | 向亲友报丧（讣告、报丧），通知奔丧 |
| 设灵 | 设灵堂、灵位（神主牌）、挂白布、点长明灯 |

### 4.2 入殓

- 择吉**入殓**（小殓、大殓），请阴阳先生看日子。
- 棺内铺陈（寿被、垫钱、亡人生前之物），讲究「**口含钱**」（铜钱/玉）等（部分人家）。
- 入殓前给亡人**洗脸**（面向、刮脸等），男剃头女梳头（各地不一）。

### 4.3 丧服戴孝（成服）

| 亲属关系 | 丧服（五服） |
| --- | --- |
| 孝子（儿子） | 斩衰：粗布孝服、麻冠、麻绳腰带，服最重 |
| 孝孙、侄子等 | 齐衰：次重 |
| 曾孙等 | 大功、小功、缌麻：依次递减 |

- 儿子**披麻戴孝**（披麻、腰系麻绳、戴孝帽、拄哭丧棒），女儿媳妇**头戴孝帕**。
- 有「**鞋头蒙白布**」等区分，重孝（父/母）鞋头白布多。
- 亲友戴白花、黑纱（现代简化）。

### 4.4 守灵

- 停灵期间**守灵**（昼夜轮流），灵前点长明灯、烧香、守夜。
- 灵堂设**灵位**，摆供、点香烛；亲友吊唁（「香仪」随礼，见《平昌红白喜事礼俗》）。
- **哭丧**：儿女哭丧（哭灵），有**唱哭丧**旧俗，哭词表达哀思，部分请人哭丧（现代渐少）。

### 4.5 出殡与送葬

- 择吉**出殡**，请阴阳先生看时辰、定向。
- 出殡仪式：**起灵**、抬棺（八人/抬杠）、**哭灵送别**、沿途撒纸钱（「买路钱」）。
- 送葬队伍：孝子抱灵排、哭丧棒；亲友相送。
- 全程讲究「**不走回头路**」。

### 4.6 下葬

- 择**墓地**（看风水、定向），掘穴（「打井」），吉时**下葬**。
- 摆棺材、垒坟（添土）、**复土**。
- 下葬后**烧纸、祭供**，众人添土（「添三把土」）。<br>有「**圆坟**」（下葬三日后上坟）之俗。

### 4.7 复山 / 圆坟

- 下葬后**复山（圆坟）**：三日后（或择日）再上坟祭拜，添新土、烧纸、摆供。
- 烧袱子「复山」期语见《平昌七月半烧袱子书写指南》4.6 节「**复土之期**」。

## 五、守孝与周年制度

### 5.1 守孝

- 传统**守孝三年**（实为二十七月，多从简）；期间孝子不剃头、不婚嫁、不赴宴（旧俗，现代多从简）。
- 丧服（五服）决定守孝轻重，长辈对晚辈、晚辈对长辈各有规制。

### 5.2 七七与百日

| 阶段 | 说明 |
| --- | --- |
| 头七 | 死后第七天，设灵祭奠 |
| 二七至七七 | 每七日设祭（「做七」），七七（断七/满七）较为隆重 |
| 百日 | 满百天卒哭，烧纸除哭 |

- 新亡期间烧袱子（「**今当新亡之期**」，七七 / 百日），见烧袱子指南 4.5 节。

### 5.3 周年与除服

| 时间 | 期语称呼（见烧袱子指南 4.6 节） |
| --- | --- |
| 死后满一年 | 小样之期（亦作小祥） |
| 死后满两年 | 大样之期（亦作大祥） |
| 死后满三年 | 除服之期 |

- 三年后称「**故显考 / 故显妣**」，三年内称「**新逝显考 / 新逝显妣**」。

## 六、上坟与扫墓

### 6.1 时机
- 清明（扫墓挂青）、春节（拜年上坟）、七月半、寒衣节、忌日、新亡百日周年。

### 6.2 仪式
1. 除杂草、培土、修整坟头。
2. 挂青 / 压纸（坟头挂白纸、彩纸、压纸钱）。
3. 点香烛、摆供（刀头、酒、水果）。
4. 烧纸 / 烧袱子（见烧袱子指南）。
5. 祭拜（作揖、跪叩），口念请祖先"享用""保佑"。
6. 撒酒（奠酒），收供。

### 6.3 本地特点
- 清明上坟重在「**挂青**」，坟头挂纸多寡象征后人香火。
- 上坟**忌**踩他人坟头、忌不敬、忌在坟前嬉闹。

## 七、立碑与迁葬

| 事项 | 说明 |
| --- | --- |
| 立碑 | 择吉立碑（坟前立石碑，刻名讳、生卒、立碑人），烧纸（「**竖碑之期**」） |
| 迁葬 | 旧墓迁新址，迁坟时「**捡骨**（迁骨）」二次安葬，烧纸（「**迁葬之期**」） |
| 复山 | 迁葬后复土，烧纸（「**复土之期**」） |

> 立碑、迁葬多请阴阳先生看风水定向；「捡骨」迁坟各地规矩差异大，以当地长辈与先生为准。

## 八、丧仪中的遗俗与禁忌

> 供参考，以当地长辈与家族惯例为准。

- **红事避白事**：家有丧事（尤其是新亡未满），不宜短期内办喜事。
- **喜丧**：高龄长寿者去世称「喜丧」，较丧事淡化悲哀、近喜庆（部分地方）。
- 出殡**不走回头路**，途中不回头张望。
- 灵前**灯不灭**（长明灯），守灵时莫灭灯。
- 丧期**不剃头、不洗脸刮胡**（重孝），以示哀痛（旧俗）。
- 未满十二岁儿童、孕妇，部分家庭习俗不强求参与丧仪。
- 烧纸**忌用红笔**写包袱、忌直书亡者名讳不避讳（见烧袱子指南第八章）。
- 墓地**忌**乱动他人祖坟、忌砍伐坟地风水树。

## 九、烧袱子要点引用

> 烧袱子是平昌七月半及多个节令的核心祭祀形式，具体封面**竖排十列**写法、「**男讳女不讳**」规则、称谓对照表（考/妣、显/先、公/母）、常用范文模板一至十、以及各节令**期语称呼**，均详见《平昌七月半烧袱子书写指南》v1.0.0。

**要点速记：**
- 单人包**十列**（右起→左），双人合包**十一列**（模板十）。
- 收者列（故显考/故显妣……）**字最大、顶格**；第一列空两格、第二列空四格。
- 男性亡者第五列写「**讳**」；女性亡者第五列写「**宅**」（男讳女不讳）。
- 收者尊称：男「**老大人**」、女「**老孺人**」。
- 三年内「**新逝显考/显妣**」，三年后「**故显考/故显妣**」。
- 期语用「**今当〈称呼〉之期**」，日期用「**公元××××年农历×月×日 坟前化帛**」。
