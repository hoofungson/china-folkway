## 一、概述

平昌地处川东北大巴山南麓，岁时节令与整个巴中、川东北一脉相承，又保留较多本地口传特色。总体特点是：**重家庭团圆、重祭祖感恩、重饮食节令**。农忙与农闲决定了不少节日的淡重——农闲时过节隆，农忙时从简（如端午、中秋与大年比平时隆重；清明、尝新等则兼具生产节气意味）。

> 本地口传：川东北有「**一三五七九，初一到十五；二月二龙抬头，晒衣六月六**」等顺口溜，节日大多与**家宅祭祀、祈福、农事节气**相关联。各地日子与做法以自家长辈口传为准。

## 三、春节（大年）

### 3.1 时间
正月初一至正月十五（元宵）为「过年」全段；本地多从腊月忙年开始，除夕「辞岁」，初一早起「拜年」，至十五「元宵」收尾。

### 3.2 主要习俗

| 阶段 | 习俗 |
| --- | --- |
| 腊月（忙年） | 扫尘、杀年猪、熏腊肉、灌香肠、打豆腐、写春联、备年货、祭灶 |
| 除夕 | 贴春联门神、吃**团年饭**（年饭）、守年、压岁钱、放爆竹、**辞岁烧纸**（烧袱子/化纸） |
| 正月初一 | 开门放炮、早起拜年、给长辈拜年、吃剩饭（寓意「年年有余」）、**开年供祖** |
| 正月初二 | 走亲访友、回娘家 |
| 正月初五 | 破五、接财神 |
| 正月十五 | 元宵、吃汤圆、亮灯、烧蛋/舞龙灯（部分乡镇） |

### 3.3 本地特色
- **团年饭**讲究「要有鱼」（年年有余）、「要有鸡」（大吉大利）、「不能把饭吃完」（留到初一，寓意有余）。
- 除夕**辞岁烧纸**：给祖先烧袱子或散纸钱，口念请祖先回家团年（写法见烧袱子指南「除夕 / 团年之期」「年尽之期」）。
- 川东北有「**初一不出门（部分人家），初二拜丈人**」的说法，各地略有出入。
- 正月初一**扫帚不外扫**、不泼水、不说不吉利话，讲究「开门红」。

## 四、元宵节（正月十五）

- **吃汤圆**：寓意团圆。
- **亮灯 / 出灯**：部分乡镇有挂灯笼、舞龙灯、耍狮、猜灯谜。
- **烧蛋**（部分家庭）：元宵夜以「烧蛋」或「偷青」等旧俗祈福，现已少见，以当地口传为准。
- 元宵前后也常是**新亡者「烧纸」**的补充时段（与烧袱子「拜年之期」衔接）。

---

## 五、二月二龙抬头

- **剃头**：民间「二月二剃龙头」，寓意转运。
- **吃豆粑 / 炒豆**：川东北有吃豆类、炒玉米花等习俗。
- **敬土地**：给土地神（地盘业主）烧纸祈福，祈求当年五谷丰登、家宅平安（写法见烧袱子「地盘业主」）。

## 六、清明（扫墓挂青）

### 6.1 时间
公历 4 月 4—6 日，寒食后一日；本地多在清明当日或清明前后数日扫墓。

### 6.2 主要习俗

| 习俗 | 说明 |
| --- | --- |
| **挂青** | 在坟头挂「坟飘」/白纸、彩纸，寓意给坟「添新衣」 |
| **扫墓** | 除杂草、培土、整修坟头 |
| **压纸/挂纸** | 在坟头压纸钱（白纸或彩纸） |
| **烧袱子** | 给先人烧包袱、化纸，写法见《平昌七月半烧袱子书写指南》「清明 / 拜扫之期」 |
| **祭供** | 摆供品（刀头肉、酒、水果、点心），点香烛 |

### 6.3 本地特点
- 川东北清明扫墓重在「**挂青**」，坟头挂纸多寡常被视为「后人多少、香火旺不旺」。
- 新坟（三年内）扫墓，有「新坟不过社」等说法，以家中长辈为准。
- 清明烧袱子常用第一列「**今当清明之期**」或「**今当拜扫之期**」。

## 七、端午（端阳）

### 7.1 时间
农历五月初五（「端午」「端阳」「蒲节」）。

### 7.2 主要习俗

| 习俗 | 说明 |
| --- | --- |
| 吃粽子 | 糯米粽（咸/甜），部分家庭包腊肉粽 |
| 挂艾草、菖蒲 | 门前挂艾、菖蒲，驱邪避疫（川东北「蒲节」源自蒲剑菖蒲） |
| 佩香囊、抹雄黄 | 小孩佩香囊，部分抹雄黄酒于额头（现代慎用雄黄，注意安全） |
| 赛龙舟 | 水乡/河流沿岸乡镇有龙舟竞渡 |
| **烧袱子** | 给先人化纸，写法见「端阳 / 蒲节之期」 |

### 7.3 本地特点
- 端午节在川东北又称「**蒲节**」，与门前挂菖蒲（蒲剑）有关；烧袱子第一列可写「**今当蒲节之期**」。
- 农家常于此节令弄「**五黄**」，各地略有差异，以当地长辈口传为准。

---

## 八、六月六（晒衣 / 尝新）

### 8.1 时间
农历六月初六。

### 8.2 主要习俗

| 习俗 | 说明 |
| --- | --- |
| **晒衣 / 晒书** | 六月六「晒衣日」，翻晒冬衣、被褥、书籍，防霉去蛀 |
| **尝新** | 早稻/新粮初熟，用新米做饭、祭祖「**吃新**」，感谢天地祖先 |
| **吃新化纸** | 给祖先烧纸，写法见「尝新 / 新荐之期」：第一列「**今当新荐之期**」 |

### 8.3 本地特点
- 川东北农家重「**吃新**」：头一锅新米先敬祖先，再全家食用，谓之「尝新」。
- 有「六月六，晒得鸭蛋熟」之谚，寓意三伏晒物。

## 九、七月半（中元节 / 月半节）

> 详见《平昌七月半烧袱子书写指南》v1.0.0（核心主题文档）。本节仅列举要点。

- **时间**：农历七月十五，民间以七月为「鬼月」，七月初一「鬼门开」，七月十五「鬼门关」。
- **核心活动**：**烧袱子**（写包袱、烧包），给亡人「寄钱寄物」。
- **本地口传**「七月半，鬼门开，十三烧袱子」——多在七月十三或十四黄昏焚烧，亦有正日十五烧。
- **流程**：接祖（七月十二前后）→ 打纸钱、写包袱 → 画圈（圈口朝祖坟/西南方向）→ 先烧特殊封（地盘业主、车夫力士）→ 圈内按辈分烧自家包袱 → 送祖（七月十五正日）。
- **写法格式**：竖排十列（单人包），男「讳」女「宅」，收者列（故显考/故显妣……）字最大；详见烧袱子指南 4.1—5 章。
- **不同时节烧袱子期语**见烧袱子指南 4.5 节（如「今当中元之期」「今当拜年之期」「今当拜扫之期」等）。

## 十、中秋

- **时间**：农历八月十五。
- **习俗**：吃月饼、赏月、家人团聚、供月（设案摆月饼水果）。
- **本地特点**：川东北农村重「团圆」，有「月圆人圆」寓意；部分家庭在院坝供月祈福。相关烧纸不多，以家庭供月为主。

---

## 十一、重阳

- **时间**：农历九月初九。
- **习俗**：登高、插茱萸、敬老（近年定为「敬老节」）、吃重阳糕（部分地方）。
- **本地特点**：以登高、敬老为主；川东北部分乡镇有「重阳蒸糕」旧俗，现渐简化。

---

## 十二、寒衣节（十月初一）

- **时间**：农历十月初一。
- **习俗**：给祖先「**送寒衣**」，焚烧纸衣、纸钱，寓意天冷为亡人添衣御寒。是七月半之外另一重要烧纸祭祖时段。
- **写法**：烧袱子第一列「**今当寒衣之期**」，详见烧袱子指南 4.5 节。

---

## 十三、腊八

- **时间**：农历腊月初八。
- **习俗**：喝腊八粥（五谷杂粮熬成）、腌腊八蒜（部分地方）。
- **本地特点**：川东北「腊八」常与备年衔接，过了腊八即「进入忙年」。

---

## 十四、小年

- **时间**：腊月二十三（北方多此日）或二十四（南方多此日），川东北各地略有差异，以当地口传为准。
- **习俗**：
  - **送灶 / 祭灶**：给灶神上供（灶糖、甜食），送灶神上天「言好事」，祈来年平安。
  - **扫尘**：腊月二十三前后大扫除，打扫庭院，寓意「除旧布新」。
- **本地注**：送灶烧纸、上香，有的家庭在灶前贴「上天言好事，下界保平安」对联。

---

## 十五、除夕（大年三十）

- **时间**：农历腊月最后一天（年三十或廿九），是春节全段的最高潮。
- **主要习俗**：

| 习俗 | 说明 |
| --- | --- |
| 贴春联、门神 | 上午贴好，寓意迎新 |
| 吃团年饭 | 阖家围坐，必有鱼（有余）、鸡（大吉），不能吃完 |
| 辞岁 / 辞年 | 祭祖、烧纸（烧袱子），口念请祖先团年 |
| 压岁钱 | 长辈给晚辈红包 |
| 守岁 | 通宵守岁，零点燃爆竹接年 |
| 打年货 / 守夜 | 部分乡镇有围炉夜话、看春晚等 |

- **烧纸写法**：除夕烧袱子第一列「**今当年尽之期**」或「**今当除岁之期**」；团年「**今当团年之期**」。

## 十六、节日禁忌总览

> 川东北民间传统说法，供参考；现代家庭不必过度拘泥，以心诚为主。

| 节日 | 说法 |
| --- | --- |
| 正月初一 | 扫帚不外扫、不泼水、不说不吉利话、不动刀剪（部分地区） |
| 正月 | 不办喜事（部分地方），忌打骂小孩 |
| 清明 | 忌在坟前嬉闹、忌不敬先人；新坟三年有「不过社」之说 |
| 七月半前后 | 夜不晾衣过夜、不吹口哨、不在野外逗留太晚（民间传说） |
| 端午前后 | 忌乱砍艾草、忌丢失香囊（旧俗）；雄黄慎用 |
| 除夕 | 不骂人、不摔碗、不吃光所有食物；灯烛宜亮（象征旺） |
