## 生成方式

- 用无头 Chrome 将 Markdown 转换的 HTML 打印成 PDF（支持中文、表格、代码块）。
- 再用 pdf-lib 追加 PDF 书签（/Outlines）。
- 生成的 PDF 已用 PDF 解析器校验：**43 页、书签结构有效**。
