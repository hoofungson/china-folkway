## 这是什么

这是《四川平昌县地方民俗知识合订本》的 PDF 版本，供**直接分享、打印、发给长辈查阅**。

- 内容与 Markdown 版一致：**卷首语 / 总目录 / 四卷正文 / 后记**。
- 覆盖平昌本地民俗：**岁时传统节日**、**祭祀与丧葬礼俗**、**红白喜事礼俗**、**七月半烧袱子书写指南**。

## 生成方式

- 用无头 Chrome 将 Markdown 转换的 HTML 打印成 PDF（支持中文、表格、代码块）。
- 再用 pdf-lib 追加**两级 PDF 书签**（/Outlines），标题采用 UTF-16BE + BOM 编码。
- 生成的 PDF 已用 PDF 解析器校验：**45 页、两级书签结构有效、中文正常**。
