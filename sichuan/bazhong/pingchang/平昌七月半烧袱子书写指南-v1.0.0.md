## 一、习俗背景

**七月半**，即农历七月十五**中元节**，民间又称"鬼节""月半节"。传说农历七月初一"鬼门开"，地府鬼魂回阳间探亲，至七月十五"鬼门关"，故七月是民间祭祖的重要月份。

在平昌及整个巴中、川东北地区，七月半祭祖的核心形式就是**烧袱子**（也称"烧包""烧包袱""写包袱"）。所谓"袱子"，就是用纸折成信封状的纸包，里面装入纸钱（冥币、金银纸锭），**封面上用毛笔竖写亡人的称谓、名讳、财帛数量、日期和化帛人**，然后焚烧，寓意给阴间的祖先"寄钱寄物"。

> 平昌本地老一辈有说法："七月半，鬼门开，十三烧袱子。"川东北不少家庭习惯在七月十三或十四傍晚焚烧，也有在十五正日烧的，各家各院略有差异，以自家长辈口传为准。

## 四、包袱封面的书写格式（核心）

### 4.1 整体版式（平昌本地十列写法）

平昌本地包袱封面为**竖排书写，自右向左共十列**（右起第一列 → 第十列），各列起笔高度有讲究。书写时把纸包正面朝上、封口朝上，用毛笔自上而下、自右而左书写。以下为按参考范本整理的标准版式：

```
右起第一列：今当中元之期　　　　　　　　　　　　（起笔空两格）
右起第二列：虔具冥财〈大写数字〉封　　　　　　　（起笔空四格）
右起第三列：奉　　　　　　　　　　　　　　　　　（字居底部）
右起第四列：上　　　　　　　　　　　　　　　　　（顶格）
右起第五列：讳　　　　　　　　　　　　　　　　　（与第六列"公"后的空格齐平，即与名字同位）
右起第六列：故显考〈姓〉公　〈名〉老大人一位正魂收用（顶格，字最大）
右起第七列：男　〈祭祀人夫姓名〉　　　　　　　　（比第八列低一格）
右起第八列：孝　跪叩　　　　　　　　　　　　　　（与第六列"老"字齐平）
右起第九列：媳　〈祭祀人妻姓名〉　　　　　　　　（比第八列低一格）
右起第十列：公元二零二六年农历七月十四日　坟前化帛（起笔空两格）
```

| 右起列序 | 书写内容 | 起笔位置 |
| --- | --- | --- |
| 第一列 | 今当中元之期 | 顶部空两格 |
| 第二列 | 虔具冥财〈大写数字〉封（壹、贰……） | 顶部空四格 |
| 第三列 | 奉 | 字居底部 |
| 第四列 | 上 | 顶格 |
| 第五列 | 讳 | 与第六列"公"后空格齐平（与名字同位） |
| 第六列 | 故显考〈姓〉公 〈名〉老大人一位正魂收用 | 顶格，**字最大** |
| 第七列 | 男 〈祭祀人夫姓名〉 | 比第八列低一格 |
| 第八列 | 孝 跪叩 | 与第六列"老"字齐平 |
| 第九列 | 媳 〈祭祀人妻姓名〉 | 比第八列低一格 |
| 第十列 | 公元××××年农历七月××日 坟前化帛 | 顶部空两格 |

**关键位置关系（依参考范本）：**
- 第一列空两格、第二列空四格、第十列空两格起笔。
- 第四列"上"顶格、第三列"奉"居底部，两列合读为"**上奉**"。
- 第五列"讳"与第六列"公"字后的空格齐平（与名字同一高度）；名字写在第六列"公"后的空格处。
- 第六列顶格，为全包字最大的一列。
- 第八列"孝 跪叩"与第六列"老大人"的"老"字齐平；第七列"男××"比第八列低一格；第九列"媳××"比第八列低一格。

**女性亡者（如母亲、祖母）的差异写法：**

```
右起第五列：宅（与第六列名字同位；男性写"讳"，女性写"宅"）
右起第六列：故显妣〈逝者夫姓〉　〈逝者姓名〉老孺人一位正魂收用（顶格，字最大）
```

- 女性包袱**第五列**由"讳"改为"**宅**"字，"宅"指其内宅故居，为对女性亡者的敬称。
- 女性包袱**第六列**写"**故显妣〈逝者夫姓〉　〈逝者姓名〉老孺人一位正魂收用**"，夫姓在前、逝者本人姓名在后（如"故显妣王　秀英老孺人一位正魂收用"）。
- 其余各列（奉送语、上奉、化帛人、日期落款）与男性写法相同。

### 4.2 十列内容说明

对照 4.1 版式，各列作用如下：

1. **第一、二列——奉送语与财帛**：第一列写"今当中元之期"（奉送语）；第二列写"虔具冥财〈大写数字〉封"（如"虔具冥财壹封"），用大写数字注明封数或包数。
2. **第三、四列——上奉**：第四列顶格写"上"，第三列底部写"奉"，合读为"上奉"，表示恭敬奉上。
3. **第五列——讳 / 宅**：单列一字，与第六列名字同位。男性亡者写"**讳**"（敬避名讳）；女性亡者写"**宅**"（指内宅故居，女性敬称）。名字写在第六列"公"（男性）或夫姓（女性）之后的空格处。
4. **第六列——收者（全包最重要）**：男性写"**故显考〈姓〉公 〈名〉老大人一位正魂收用**"（如"故显考张公 志强老大人一位正魂收用"）；女性写"**故显妣〈夫姓〉 〈逝者姓名〉老孺人一位正魂收用**"（如"故显妣王 秀英老孺人一位正魂收用"）。**字最大、顶格**。
5. **第七、八、九列——化帛人**：第八列写"孝 跪叩"（与第六列"老"字齐平），第七列写"男〈夫姓名〉"，第九列写"媳〈妻姓名〉"，分别比第八列低一格，表示儿孙媳辈跪叩奉送。
6. **第十列——日期落款**：写"公元××××年农历七月××日 坟前化帛"，注明焚烧日期与地点。

### 4.3 写法要点

- **称谓要准确**：考/妣、显/先、公/母等不能写错（见第五章对照表），写错等于送错人。
- **名讳要避讳**：男性亡者第五列写"讳"，女性亡者写"宅"，均与名字同位；名字只写名、不写姓（男性姓已含在"×公"中，女性以夫姓起首）。
- **用字讲究**：父母辈用"显考 / 显妣"，祖辈以上用"祖考 / 祖妣、曾祖考 / 曾祖妣、高祖考 / 高祖妣"；若亡者去世时其父辈仍健在（或家族中有更长辈），则用"先考 / 先妣"以示谦抑。
- **尊称**：男性亡者称"老大人"，女性亡者称"老孺人"（或"老安人"）。
- **字迹工整**：忌潦草、忌错别字、忌涂改；写错请重写一张，不可划掉。
- **颜色**：一律用黑墨，**忌用红笔**。
- **封口**：包好纸钱、写完后用浆糊封口，封口处可再贴一条"封条"。

| --- | --- | --- | --- |
| 2024 | 甲辰年 | 8 月 18 日 | 公元二零二四年农历七月十五日 |
| 2025 | 乙巳年 | 9 月 6 日 | 公元二零二五年农历七月十五日 |
| **2026** | **丙午年** | **8 月 27 日** | **公元二零二六年农历七月×日** |

### 4.5 不同时节的称呼与日期写法

烧袱子不限于七月半：**新年、清明、端阳、腊月、除夕、亡者忌日、新亡七七百日**等时节同样要烧，只是**第一列奉送语**和**第十列（双人合包为第十一列）日期落款**随时节变化；收者部分（第五至七列）、化帛人列及"男讳女不讳"规则均不变。

| 烧袱子时节 | 期语称呼 | 第一列奉送语写法 | 日期落款写法示例 |
| --- | --- | --- | --- |
| 七月半（中元节） | 中元之期 | 今当中元之期 | 公元二零二六年农历七月十四日 坟前化帛 |
| 新年 | 拜年之期 | 今当拜年之期 | 公元××××年农历正月初×日 坟前化帛 |
| 清明（扫墓挂青） | 拜扫之期 | 今当拜扫之期（或"今当清明之期"） | 公元××××年农历三月×日（清明）坟前化帛 |
| 端阳（端午） | 蒲节之期 | 今当蒲节之期 | 公元××××年农历五月初五日 坟前化帛 |
| 腊月 | 岁终之期 | 今当岁终之期 | 公元××××年农历腊月×日 坟前化帛 |
| 除夕（年三十 / 辞岁） | 年尽之期 | 今当年尽之期（或"今当除岁之期"） | 公元××××年农历腊月三十日 坟前化帛 |

| 亡者忌日 / 周年 | — | 今当先考（先妣）讳日，或"今逢忌辰" | 公元××××年农历×月×日 坟前化帛 |
| 新亡（七七 / 百日 / 满百天卒哭） | 卒哭之期（满百天） | 今当新亡之期（七七 / 百日） | 公元××××年农历×月×日 坟前化帛 |

**说明：**
- **期语称呼**即本地口传时节称呼（详见 4.6 节收语规则），使用时写成"今当〈称呼〉"，如"今当中元之期"。
- 日期一律用"**公元××××年农历×月×日**"，末尾写"坟前化帛"；如提前烧（如清明提前数日），按**实际焚烧当天**的农历日期填写。
- 忌日、周年按亡者实际去世日期写；如"三周年"可加注"三周年"字样。
- 模板一至十的第一列与日期落款，按上表替换时节用语即可，其余各列不变。

## 五、称谓称呼对照表

> 表中"〈姓〉/〈夫姓〉"为亡者（夫家）姓，"〈名〉/〈逝者姓名〉"为亡者名（写在右起第六列"公"或夫姓后的空格处）。**请按自家情况替换。**

**基本规则：**
- **男称**：大人；**女称**：孺人。

- **用讳**：男讳、女不讳（男性第五列写"讳"，女性写"宅"）。

**称谓常识：**
- **考**＝已故的父亲，**妣**＝已故的母亲；"故考 / 故妣"即"已故的父亲 / 母亲"。
- **显**＝有德望、受尊敬（多用于父母、祖辈）；**先**＝通用谦称（父辈先亡时用"先考"更合礼数）。
- **讳 / 宅**：第五列单列一字，与第六列名字同位。男性亡者写"**讳**"（敬避名讳），女性亡者写"**宅**"（指内宅故居，女性敬称）。
- **老大人 / 老孺人**＝对亡故男女长辈的尊称。
- **一位正魂收用**＝平昌本地常用收语（指亡者本人魂魄收受）；平辈、晚辈也可简写"收"。
- 夫妻亡者可写**合包**（一封包两人），按模板十的十一列交错版式书写（男讳女不讳）；也可各写一封。

- "男"泛指家中男性后嗣（儿、孙、曾孙辈均可写"男"），"媳"指其妻子（儿媳、孙媳）；同辈或平辈祭祀人按实际称谓写"兄 / 弟 / 姐 / 妹 / 妻 / 夫"等。
- 化帛人列有起笔高低讲究：单人包第七列"男××"比第八列"孝 跪叩"低一格、第九列"媳××"再比第八列低一格；双人合包第八列"男××"比第九列低一格、第十列"媳××"比第九列低一格（见模板一、模板十）。
- 家中多人同烧时，可多个名字并列写于一列，也可分列书写；以自家长辈惯例为准。

   公             〈男逝者〉          宅

## 七、焚烧礼仪与步骤

1. **接祖（七月十二前后）**：傍晚在堂屋或院坝摆供桌，点香烛，烧几张散钱纸，口念"祖先回家过节"，此后每日三餐前上香。
2. **打纸钱**：用钱凿在草纸上打铜钱印；装入包袱封好、写好封面。
3. **画圈**：在院坝空地上用草木灰画一个圈，**圈口朝向祖坟方向**（或传统所指的西北方向），圈内烧自家包袱。
4. **先烧特殊封**：先在**圈外**烧"地盘业主""车夫力士"包，再在**圈内**按辈分从高到低烧自家包袱。
5. **逐一焚烧**：每烧一封念诵，如"××公（称呼），七月半了，给您送钱来了，请收好，在那边吃饱穿暖，保佑子孙平安。"
6. **烧透烧尽**：用长棍轻轻挑开，确保烧透；**中途不翻搅过猛**，民间认为会惊扰亡人收钱。
7. **送祖（七月十五）**：正日傍晚再烧一批纸钱，泼一碗"水饭"（清水泡冷饭）送祖先归去，撤供。
8. **收尾**：待火完全熄灭、灰烬冷却后再离开；灰烬按当地习惯倒入河沟或埋入土中，不混入生活垃圾。

## 八、禁忌与民俗讲究

> 以下为平昌本地及川东北民间传统说法，供参考；现代家庭不必过度拘泥，以心诚为主。

- **忌红笔**书写包袱，对亡人不敬。
- 亡人**名讳不可写错**、不可直书其名不避讳。
- 写错或写坏的字纸**不可乱丢**，宜随包袱一并焚化。
- 焚烧时**不宜大声呼喊活人全名**，以免惊扰。
- 未满十二岁儿童、孕妇，部分家庭习俗不参与焚烧。
- 不拾取、不踩踏他人焚烧的纸灰与包袱。
- 圈内钱**不可用木棍乱捅**、不可烧一半取走。
- 七月半前后夜晚传统讲究：不晾晒衣物过夜、不吹口哨、不在野外逗留太晚（民间传说，理性看待）。
- 新亡未满三年之家，部分地方有"新坟三年不过七月半"或提前烧的讲究，**以家中长辈说法为准**。

## 九、文明祭祀与安全提示

- 平昌县城及乡镇近年倡导**文明祭祀**，城区设有集中焚烧点，请先在社区 / 物业确认可焚烧地点。
- **严禁**在林地、草丛、秸秆堆、燃气管道附近焚烧；烧完确认**火种完全熄灭**再离开，人走火灭。
- 提倡**鲜花祭祀、电子香烛、网上祭扫**等绿色方式；焚烧时减少塑料冥币（燃烧产生有害气体）。
- 购买纸钱请选正规渠道，注意防火包装，焚化后清理现场。
