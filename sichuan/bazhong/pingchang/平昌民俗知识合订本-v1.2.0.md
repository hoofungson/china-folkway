## 一、概述

平昌地处川东北大巴山南麓，岁时节令与整个巴中、川东北一脉相承，又保留较多本地口传特色。总体特点是：**重家庭团圆、重祭祖感恩、重饮食节令**。农忙与农闲决定了不少节日的淡重——农闲时过节隆，农忙时从简（如端午、中秋与大年比平时隆重；清明、尝新等则兼具生产节气意味）。

> 本地口传：川东北有「**一三五七九，初一到十五；二月二龙抬头，晒衣六月六**」等顺口溜，节日大多与**家宅祭祀、祈福、农事节气**相关联。**端午用新收小麦磨面做包子**是本地常见吃法；**家宅常年供奉天地君亲师、灶神菩萨，初一十五上香点灯，小年送迎灶神**。**年关（大寒至立春）**是本地打扫坟、动土营造的时令；**新坟三年内不扫坟垒土**。各地日子与做法以自家长辈口传为准。

> **年关时令**：本地一般在**大寒至立春之间**才**打扫坟、动坟土**，以及**动土修房造屋**（破土、立基、修房）。这段时节大体覆盖**小年、除夕、春节**前后，正是「年关」。详见《平昌祭祀与丧葬礼俗》第九章（上坟与扫墓）、第十章（立碑与迁葬）。
> **新坟三年**：新坟（亡后三年内）一般**不能扫坟、垒土、动坟土**，只可祭拜、挂纸、烧纸；**满三年**才能扫坟、垒土（详见《平昌祭祀与丧葬礼俗》第九章）。

## 三、春节（大年）

### 3.1 时间

正月初一至正月十五（元宵）为「过年」全段；本地多从腊月忙年开始，除夕「辞岁」，初一早起「拜年」，至十五「元宵」收尾。

### 3.2 主要习俗

| 阶段     | 习俗                                               |
| ------ | ------------------------------------------------ |
| 腊月（忙年） | 扫尘、杀年猪、熏腊肉、灌香肠、打豆腐、写春联、备年货、祭灶                    |
| 除夕     | 详见第十五章：**煮刀头肉上坟请祖、中午团年饭放爆竹、火塘守岁、交夜出天行**          |
| 正月初一   | **大开全家的门迎财神**、早起拜年（不能睡懒觉）、吃剩饭（寓意「年年有余」）、**开年供祖** |
| 正月初二   | 走亲访友、回娘家                                         |
| 正月初五   | 破五、接财神                                           |
| 正月十五   | 元宵、吃汤圆、亮灯、烧蛋/舞龙灯（部分乡镇）                           |

### 3.3 本地特色

- **团年饭**讲究「要有鱼」（年年有余）、「要有鸡」（大吉大利）、「不能把饭吃完」（留到初一，寓意有余）。
- 除夕**辞岁烧纸**：给祖先烧袱子或散纸钱，口念请祖先回家团年（写法见烧袱子指南「除夕 / 团年之期」「年尽之期」）。
- 除夕**火塘守岁**：提前挖一棵**干的大树脑壳**（树根/树墩）生火，全家围火塘守岁；**火越旺，寓意来年喂养的年猪又肥又壮**（详见 15.3）。
- 除夕**交夜出天行**：半夜子时燃放烟花爆竹迎新（详见 15.4）。
- 大年初一早**大开全家的门**，寓意「**迎财神**」；初一**不能睡懒觉**（详见 16）。
- 川东北有「**初一不出门（部分人家），初二拜丈人**」的说法，各地略有出入。
- 正月初一**扫帚不外扫**、不泼水、不说不吉利话，讲究「开门红」。

## 四、元宵节（正月十五）

- **吃汤圆**：寓意团圆。
- **亮灯 / 出灯**：部分乡镇有挂灯笼、舞龙灯、耍狮、猜灯谜。
- **烧蛋**（部分家庭）：元宵夜以「烧蛋」或「偷青」等旧俗祈福，现已少见，以当地口传为准。
- 元宵前后也常是**新亡者「烧纸」**的补充时段（与烧袱子「拜年之期」衔接）。

---

## 五、二月二龙抬头

- **剃头**：民间「二月二剃龙头」，寓意转运。
- **吃豆粑 / 炒豆**：川东北有吃豆类、炒玉米花等习俗。
- **敬土地**：给土地神（地盘业主）烧纸祈福，祈求当年五谷丰登、家宅平安（写法见烧袱子「地盘业主」）。

## 六、清明（扫墓挂青）

### 6.1 时间

公历 4 月 4—6 日，寒食后一日；本地多在清明当日或清明前后数日扫墓。

### 6.2 主要习俗

| 习俗        | 说明                                     |
| --------- | -------------------------------------- |
| **挂青**    | 在坟头挂「坟飘」/白纸、彩纸，寓意给坟「添新衣」               |
| **扫墓**    | 除杂草、培土、修整坟头                            |
| **压纸/挂纸** | 在坟头压纸钱（白纸或彩纸）                          |
| **烧袱子**   | 给先人烧包袱、化纸，写法见《平昌七月半烧袱子书写指南》「清明 / 拜扫之期」 |
| **祭供**    | 摆供品（刀头肉、酒、水果、点心），点香烛                   |

### 6.3 本地特点

- 川东北清明扫墓重在「**挂青**」，坟头挂纸多寡常被视为「后人多少、香火旺不旺」。
- **新坟（三年内）**：本地新坟清明一般**不能扫坟、垒土、动坟土**，只可祭拜、挂纸、烧纸；**满三年**才能扫坟、垒土。另有「新坟不过社」等说法，以家中长辈为准。
- 清明烧袱子常用第一列「**今当清明之期**」或「**今当拜扫之期**」。

## 七、端午（端阳）

### 7.1 时间

农历五月初五（「端午」「端阳」「蒲节」）。

### 7.2 主要习俗

| 习俗            | 说明                                |
| ------------- | --------------------------------- |
| **吃包子（本地常见）** | **用新收小麦磨成面做包子**，是本地端午常见吃法（详见 7.3） |
| 吃粽子           | 糯米粽（咸/甜），部分家庭包腊肉粽                 |
| 挂艾草、菖蒲        | 门前挂艾、菖蒲，驱邪避疫（川东北「蒲节」源自蒲剑菖蒲）       |
| 佩香囊、抹雄黄       | 小孩佩香囊，部分抹雄黄酒于额头（现代慎用雄黄，注意安全）      |
| 赛龙舟           | 水乡/河流沿岸乡镇有龙舟竞渡                    |
| **烧袱子**       | 给先人化纸，写法见「端阳 / 蒲节之期」              |

### 7.3 本地特点

- **本地端午多吃包子**：一般用**新收的小麦磨成面**做包子，所以本地端午节**吃包子比较常见**（与吃粽子并行，各地以自家习惯为准）。
- 端午节在川东北又称「**蒲节**」，与门前挂菖蒲（蒲剑）有关；烧袱子第一列可写「**今当蒲节之期**」。
- 农家常于此节令弄「**五黄**」，各地略有差异，以当地长辈口传为准。

## 八、六月六（晒衣 / 尝新）

### 8.1 时间

农历六月初六。

### 8.2 主要习俗

| 习俗          | 说明                                   |
| ----------- | ------------------------------------ |
| **晒衣 / 晒书** | 六月六「晒衣日」，翻晒冬衣、被褥、书籍，防霉去蛀             |
| **尝新**      | 早稻/新粮初熟，用新米做饭、祭祖「**吃新**」，感谢天地祖先      |
| **吃新化纸**    | 给祖先烧纸，写法见「尝新 / 新荐之期」：第一列「**今当新荐之期**」 |

### 8.3 本地特点

- 川东北农家重「**吃新**」：头一锅新米先敬祖先，再全家食用，谓之「尝新」。
- 有「六月六，晒得鸭蛋熟」之谚，寓意三伏晒物。

## 九、七月半（中元节 / 月半节）

> 详见《平昌七月半烧袱子书写指南》v1.0.0（核心主题文档）。本节仅列举要点。

- **时间**：农历七月十五，民间以七月为「鬼月」，七月初一「鬼门开」，七月十五「鬼门关」。
- **核心活动**：**烧袱子**（写包袱、烧包），给亡人「寄钱寄物」。
- **本地口传**「七月半，鬼门开，十三烧袱子」——多在七月十三或十四黄昏焚烧，亦有正日十五烧。
- **流程**：接祖（七月十二前后）→ 打纸钱、写包袱 → 画圈（圈口朝祖坟/西南方向）→ 先烧特殊封（地盘业主、车夫力士）→ 圈内按辈分烧自家包袱 → 送祖（七月十五正日）。
- **写法格式**：竖排十列（单人包），男「讳」女「宅」，收者列（故显考/故显妣……）字最大；详见烧袱子指南 4.1—5 章。
- **不同时节烧袱子期语**见烧袱子指南 4.5 节（如「今当中元之期」「今当拜年之期」「今当拜扫之期」等）。

## 十、中秋

- **时间**：农历八月十五。
- **习俗**：吃月饼、赏月、家人团聚、供月（设案摆月饼水果）。
- **本地特点**：川东北农村重「团圆」，有「月圆人圆」寓意；部分家庭在院坝供月祈福。相关烧纸不多，以家庭供月为主。

---

## 十一、重阳

- **时间**：农历九月初九。
- **习俗**：登高、插茱萸、敬老（近年定为「敬老节」）、吃重阳糕（部分地方）。
- **本地特点**：以登高、敬老为主；川东北部分乡镇有「重阳蒸糕」旧俗，现渐简化。

---

## 十二、寒衣节（十月初一）

- **时间**：农历十月初一。
- **习俗**：给祖先「**送寒衣**」，焚烧纸衣、纸钱，寓意天冷为亡人添衣御寒。是七月半之外另一重要烧纸祭祖时段。
- **写法**：烧袱子第一列「**今当寒衣之期**」，详见烧袱子指南 4.5 节。

---

## 十三、腊八

- **时间**：农历腊月初八。
- **习俗**：喝腊八粥（五谷杂粮熬成）、腌腊八蒜（部分地方）。
- **本地特点**：川东北「腊八」常与备年衔接，过了腊八即「进入忙年」。

---

## 十四、小年（祭灶：送灶 / 迎灶）

- **时间**：腊月二十三、二十四；川东北各地**送灶与迎灶两日连做**，以当地口传为准。
- **本地做法**：
  - **腊月二十三 · 送灶**：给灶头供奉的**灶神菩萨上香、点灯**，**恭送灶神菩萨上天**（回天庭），向天帝**汇报当家一年生活状况**（灶神上天「言好事」，祈来年平安）。
  - **腊月二十四 · 迎灶**：再**上香、点灯**，**迎接灶神菩萨下界归位**，庇佑来年家宅平安。
- **习俗补充**：
  - **扫尘**：腊月二十三前后大扫除，打扫庭院，寓意「除旧布新」。
  - 灶前贴「**上天言好事，下界保平安**」对联。
- **年关动土**：大寒、立春正处「年关」，本地多在此间**打扫坟、动土营造**（详见《平昌祭祀与丧葬礼俗》第九章、第十章）。
- **衔接**：家宅常年供灶神菩萨（见《平昌祭祀与丧葬礼俗》v1.7.0 家宅祭祀）；祭灶化纸与送迎灶日子各地说法略有不同，以当地长辈口传为准。

## 十五、除夕（大年三十）

### 15.1 时间

农历腊月最后一天（年三十或廿九），是春节全段的最高潮。本地流程自**上午上坟请祖**起，贯穿至**午夜出天行**。

### 15.2 除夕当天流程（平昌本地）

| 时段         | 事项            | 说明                                                                       |
| ---------- | ------------- | ------------------------------------------------------------------------ |
| **上午**     | **煮刀头肉、上坟请祖** | 家中煮好一块**边长约 15 厘米的正方形腊肉（刀头肉）**；端上刀头肉、香烛、纸钱和鞭炮，去已故先祖坟地**上坟祭祀**，口念请先祖们回家团年 |
| **中午**     | **团年饭**       | 备一大桌美食佳肴**团年**；**吃饭前燃放爆竹**                                               |
| **夜里**     | **火塘守岁**      | 全家围火塘守岁（见 15.3）；**火越旺寓意来年年猪越肥壮**                                         |
| **交夜（子时）** | **出天行**       | 半夜子时燃放烟花爆竹迎新（见 15.4）                                                     |

> 本地口传：除夕团圆，「**请祖先回家团年**」是上午上坟的宗旨；中午团年饭前放爆竹，寓意「接年、催年」。

### 15.3 火塘守岁与寓意

- 除夕夜**提前挖一棵干的大树脑壳**（树根／树墩）生火，全家围**火塘**守岁取暖。
- **寓意**：守岁期间**火越旺，来年喂养的年猪就越又肥又壮**——火旺与年猪肥壮、来年兴旺挂钩。
- 规矩：守岁火塘不宜熄；交夜（子时）前全家围坐，边守边有寓意吉利的招待。

### 15.4 出天行（交夜迎新）

- **除夕夜交夜（半夜子时）**为「出天行」之时，**燃放烟花爆竹**，迎接新年到来。
- 寓意：送旧迎新，祈求来年人畜平安、六畜兴旺。

### 15.5 烧纸写法

- 除夕烧袱子第一列「**今当年尽之期**」或「**今当除岁之期**」；团年「**今当团年之期**」（详见《平昌七月半烧袱子书写指南》4.5 节）。

## 十六、大年初一（迎财神）

- **开门迎财神**：初一早上一家人起床后，**大开全家的门**，寓意「**迎财神**」，期望新年财源广进。
- **不能睡懒觉**：大年初一**不能睡懒觉**，讲究早起「抢个好彩头」、精神一年。
- **拜年**：早起给长辈拜年、给近亲近邻拜年；吃剩饭（年年有余）。
- **开年供祖**：摆供祭祖、烧纸（开年供祖），见烧袱子指南「拜年之期」。

> 本地口传：初一「**开门红、迎财神**」，开门越早越吉利；睡懒觉被视为「懒一年」。

## 一、概述

平昌及川东北的祭祀与丧葬，核心是「**敬天法祖、慎终追远**」。祭祀分**家宅祭祀**（天地君亲师、历代先祖、灶神、土地、门神、财神）与**祠墓祭祀**（上坟、立碑、扫墓、烧袱子）；丧葬则以「**送亡人最后一程**」为要，讲究程序、孝道与厚葬。

> 本地口传：平昌丧葬重「**孝**」与「**礼**」，流程多而繁，但以「**让亡人走得体面、让后人心里安宁**」为本。**堂屋**既是祭祀中心，也是**白事停灵与做法事的场所**；**五服**是规定亲属服丧轻重与期限的核心制度。**祭祀仪礼**讲究「上香、跪拜」二仪节（见第五章）。各地具体规矩差异较大，以当地长辈、阴阳先生（地理先生）和家族惯例为准。

## 三、家宅祭祀（堂屋镇宅神位与灶神菩萨）

> 家宅祭祀是平昌各家**最日常**的祭祀，以**堂屋神位**与**灶屋灶神**为核心，全年「初一、十五」上香点灯，年节送迎灶神。

### 3.1 堂屋与镇宅神位

- 平昌家家户户通常有一间**宽大的堂屋**（正堂、客堂），堂屋供奉**镇宅神位**（家宅中央的神位案桌），是全家祭祀的中心。
- 神位的**中榜**（正中主位）一般书写「**天地君亲师位**」——即「天、地、君（国）、亲（祖先）、师」，为传统家宅祭祀的最高尊位。
- 神位中榜**两边**一般供奉**本家历代先祖**（列祖列宗）与**地盘业主**（当地土地／宅基旧主）。
- 逢农历**初一、十五**都要在神位前**上香、点灯**祭拜，祈求家宅平安、人丁兴旺。
- **堂屋的另一核心功能**：**承接白事停灵与部分法事**。家中办白事时，通常在堂屋**停灵、设灵堂、守灵**，并在此**做法事**（如开路、超度等）；故堂屋既是生者祭祀敬神之地，也是送别亡人、做法事的场所。

> 各地所供神位略有出入（亦见「天地国亲师」等写法），以自家长辈口传与家谱为准。

### 3.2 灶屋与灶神菩萨

- 每家都有**灶屋**（厨房），**灶头**供奉**灶神菩萨**（灶神，民间称「一家之主、司命之神」，管一家祸福）。
- 每年**腊月二十三**，给灶神菩萨**上香、点灯**，**恭送灶神菩萨上天**（回天庭），向玉帝**汇报当家一年生活状况**（灶神上天「言好事」）。
- **腊月二十四**，再**上香、点灯**，**迎接灶神菩萨下界归位**（各归其位），庇佑来年。

> 送灶／迎灶具体节令详见《平昌岁时传统节日民俗》「小年」；灶神位亦常贴「上天言好事，下界保平安」对联。上香、跪拜仪礼见第五章。

### 3.3 与烧袱子 / 节令衔接

- 家宅祭祀日常以「**上香、点灯**」为主（初一、十五）；逢正式祭祖节令（春节、清明、七月半、寒衣节、忌日）则**烧袱子（化纸）**。
- 「地盘业主」特殊封烧纸写法见《平昌七月半烧袱子书写指南》「特殊封——地盘业主」。

## 五、祭祀仪礼（上香与跪拜）

> 祭祀（敬神、祭祖）有其既定仪节，核心是**上香**与**跪拜**。平昌民间讲究「**上香三炷、点烛一对、作揖跪拜、默念所祈**」。

### 5.1 上香流程

| 步骤      | 做法                                                        |
| ------- | --------------------------------------------------------- |
| 1. 净手净意 | 上香前先净手（洗手），存「诚敬」之心                                        |
| 2. 取香   | 取**三炷**香并齐（敬神、祭祖同用三炷）                                     |
| 3. 点香   | 用烛火点燃，火头向上；若香起明火宜**用手扇灭**，**忌用口吹**                        |
| 4. 持香   | 双手将香握于胸前，香头朝上，举至与眉齐（「举香过眉」），躬身                            |
| 5. 插香   | 将三炷香依次插入香炉，**先中、后左、再右**（第一炷敬主位，二、三炷分两边），竖直不歪；亦见**左手插香**之说 |
| 6. 行礼   | 插香后**作揖／跪拜**（见 5.2），默念所祈                                  |
| 7. 默祷   | 静立片刻，合掌或作揖，默念所敬所祈（如「请祖先保佑」「祈家宅平安」）                        |

**要点：**

- 香数一般为**三炷**（天地君亲师、灶神、祖先皆可）；极郑重的大祭可用五炷、七炷。
- **香宜点着、插稳**，忌香插歪、香倒、香断；上香后**灯火宜亮**。
- 点香的火源用烛，忌用打火机直点（部分讲究）；以当地人为准。

### 5.2 跪拜流程

| 步骤    | 做法                                                     |
| ----- | ------------------------------------------------------ |
| 1. 站位 | 面向神位／灵位／坟墓，立正，双足并拢，目视前方                                |
| 2. 作揖 | 双手合十（或抱拳）于胸前，躬身行礼（一次或三次）                               |
| 3. 下跪 | 双膝落地（先右膝后左膝或同时），跪于垫上／地面                                |
| 4. 叩首 | 俯身，额头触地（叩首）；次数按「**人一、神三、鬼四**」——拜生人一叩、拜神明三叩、拜亡人（鬼/祖先）四叩 |
| 5. 起身 | 先起一膝，再起另一膝，起身后复作揖一次收礼                                  |
| 6. 默念 | 叩首时默念所敬所祈（请祖先／神明保佑）                                    |

**拜法差别（叩首次数遵循「人一神三鬼四」）：**

- **人一**：拜**活人**（父母、长辈、师长等）——叩一个头（一拜）。
- **神三**：拜**神明**（天地君亲师、灶神、各类神菩萨等）——叩三个头（三拜）。
- **鬼四**：拜**亡人**（去世祖先、亡灵、孤魂）——叩四个头（四拜）。
- **三跪九叩**：祭**天地、正家神**等至极尊位时的更高礼——跪三次，每次三叩，共九叩（极少的特大礼）。
- **作揖**：平辈、朋友、拜谢用，不跪。

**本地要点：**

- 拜祖重「**孝**」，拜神重「**敬**」；皆可跪拜，拜祖更讲究「叩首」。
- 妇女、幼童、孕妇是否跪拜，各地从简（以站立作揖／下拜代替），以长辈与宗族惯例为准。
- 叩首时手的位置：双手合十或双手前撑，当地说法不一，以长辈口传为准。

### 5.3 与家宅祭祀、祭祖衔接

- **家宅神位／灶神**（初一十五、送迎灶）：上香、点灯 + 作揖／跪拜，详见第三章。
- **上坟、烧袱子、立碑**等祭祖仪式：均循「上香 → 跪拜 → 默念」之序，详见第九章、第十章及《平昌七月半烧袱子书写指南》。

## 六、丧葬全程礼仪（白事）

### 6.1 临终与初丧

| 步骤       | 说明                          |
| -------- | --------------------------- |
| 送终       | 亲人守在床前，送亡人最后一程；讲究「断气前赶到」    |
| 烧倒头纸/落气纸 | 亡人落气后，烧纸钱（倒头纸/落气纸），口念送行     |
| 沐浴更衣     | 给亡人擦身、穿寿衣（「装老衣」，件数讲究三、五、七）  |
| 报丧       | 向亲友报丧（讣告、报丧），通知奔丧           |
| 设灵       | **在堂屋设灵堂**、灵位（神主牌）、挂白布、点长明灯 |

### 6.2 入殓

- 择吉**入殓**（小殓、大殓），请阴阳先生看日子。
- 棺内铺陈（寿被、垫钱、亡人生前之物），讲究「**口含钱**」（铜钱/玉）等（部分人家）。
- 入殓前给亡人**洗脸**（面向、刮脸等），男剃头女梳头（各地不一）。

### 6.3 丧服戴孝（成服）

> 丧服依**五服**而定，见第七章「五服知识体系」（含判断是否在五服内的方法，见 7.5）；此处仅列常见服等。

| 亲属关系  | 丧服（五服） | 服期  |
| ----- | ------ | --- |
| 子（儿子） | 斩衰     | 三年  |
| 孙、侄子等 | 齐衰     | 一年  |
| 堂兄弟等  | 大功     | 九月  |
| 从祖亲属等 | 小功     | 五月  |
| 族亲、远亲 | 缌麻     | 三月  |

- 儿子**披麻戴孝**（披麻、腰系麻绳、戴孝帽、拄哭丧棒），女儿媳妇**头戴孝帕**。
- 有「**鞋头蒙白布**」等区分，重孝（父/母）鞋头白布多。
- 亲友戴白花、黑纱（现代简化）。

### 6.4 守灵（多在堂屋）

- 停灵期间**守灵**（昼夜轮流），**通常设于堂屋**（见第三章堂屋功能），灵前点长明灯、烧香、守夜。
- 灵堂设**灵位**，摆供、点香烛；亲友吊唁（「香仪」随礼，见《平昌红白喜事礼俗》）。
- **哭丧**：儿女哭丧（哭灵），有**唱哭丧**旧俗，哭词表达哀思，部分请人哭丧（现代渐少）。

### 6.5 出殡与送葬

- 择吉**出殡**，请阴阳先生看时辰、定向。
- 出殡仪式：**起灵**、抬棺（八人/抬杠）、**哭灵送别**、沿途撒纸钱（「买路钱」）。
- 送葬队伍：孝子抱灵排、哭丧棒；亲友相送。
- 全程讲究「**不走回头路**」。

### 6.6 下葬

- 择**墓地**（看风水、定向），掘穴（「打井」），吉时**下葬**。
- 摆棺材、垒坟（添土）、**复土**。
- 下葬后**烧纸、祭供**，众人添土（「添三把土」）。<br>有「**圆坟**」（下葬三日后上坟）之俗。

### 6.7 复山 / 圆坟

- 下葬后**复山（圆坟）**：三日后（或择日）再上坟祭拜，添新土、烧纸、摆供。
- 烧袱子「复山」期语见《平昌七月半烧袱子书写指南》4.6 节「**复土之期**」。

## 七、五服知识体系（丧服与服丧）

> 五服是传统丧礼中按**与亡者亲属关系的远近**而定的**五种丧服等级**，每等对应不同的**服期（守制长短）**。关系越近服越重、期越长；越远服越轻、期越短。**五服之内**为「有服」亲属，**出五服**则关系疏远、不再服丧。

### 7.1 五种服等与服期一览

| 服等     | 服饰（传统）                               | 服期                       | 主要内容                                           |
| ------ | ------------------------------------ | ------------------------ | ---------------------------------------------- |
| **斩衰** | 粗生麻布、**不缝缉边**，麻冠、麻绖（麻腰带）、苴杖（哭丧棒）、粗麻鞋 | **三年**（实约二十七个月）          | 子为父、未嫁女为父、妻为夫、承重孙为祖父（父先亡）等                     |
| **齐衰** | 生麻布、**缝缉边**，无苴杖（杖期执杖）                | 依次为三年、杖期（一年）、期（一年）、五月、三月 | 孙为祖父母、子女为母（父在杖期）、为伯叔父母、兄弟、为曾祖父母（五月）、为高祖父母（三月）等 |
| **大功** | 熟麻布（粗白布）、缝缉                          | **九月**                   | 为堂兄弟、已嫁姊妹、从父兄弟、为兄弟之子（侄）等                       |
| **小功** | 细麻布（稍细白布）、缝缉                         | **五月**                   | 为从祖父母、堂伯叔父母、从祖兄弟、外祖父母、为舅、为外甥等                  |
| **缌麻** | 最细熟麻布、缝缉                             | **三月**                   | 为族兄弟、曾祖父母（另列）、外孙、婿、岳父母、庶母等                     |

> 备注：各「服期」数月为传统约数；**「三年」实为二十七个月**（一说二十五、三六月，以当家《家礼》及长辈口传为准）。

### 7.2 五服亲属关系对照表（常见）

| 对象（亡者与服者关系） | 服等   | 服期  |
| ----------- | ---- | --- |
| 子为父         | 斩衰   | 三年  |
| 子为母（父已故）    | 齐衰   | 三年  |
| 子为母（父在）     | 齐衰杖期 | 一年  |
| 妻为夫         | 斩衰   | 三年  |
| 夫为妻         | 齐衰杖期 | 一年  |
| 孙为祖父母       | 齐衰   | 一年  |
| 为曾祖父母       | 齐衰   | 五月  |
| 为高祖父母       | 齐衰   | 三月  |
| 为伯叔父母       | 齐衰   | 一年  |
| 为兄弟（在室姊妹）   | 齐衰   | 一年  |
| 为堂兄弟        | 大功   | 九月  |
| 为兄弟之子（侄）    | 大功   | 九月  |
| 为从祖父母、堂伯叔父母 | 小功   | 五月  |
| 为外祖父母       | 小功   | 五月  |
| 为舅、为外甥      | 小功   | 五月  |
| 为族兄弟        | 缌麻   | 三月  |
| 为外孙、为婿、为岳父母 | 缌麻   | 三月  |
| 为庶母（父妾）     | 缌麻   | 三月  |

> 注：以上为主流「家礼」常见对应，各宗族家谱《家礼》与地方口传或略有出入；具体以**本家《家礼》、宗谱及长辈口传为准**。

### 7.3 服丧行为与守制

- **服期越长、守制越重**：斩衰三年最重，缌麻三月最轻。
- **守制行为**（旧俗，现代多从简）：服丧期内**不剃头、不婚嫁、不赴宴、不穿艳色、不演乐、不坐宴**；居丧以哀、以孝为本。
- **重孝（斩衰）**：孝子守孝**三年**，居丧守制，常常「不剃头、不洗脸刮胡」（以示哀痛）。<br>**次重（齐衰）**：守一年或按服期。<br>**轻服（大功、小功、缌麻）**：守期较短的九、五、三月。

### 7.4 本地（平昌 / 川东北）特点

- 民间常说「**出了五服**」：指与亡者血缘已超过五服亲属范围，关系疏远，可**不通丧、不设灵、不留宿、不必执丧服**；「**本家五服**」则指同宗近亲，丧事须到场。
- **现代简化**：多以**白帕（孝帕）、白花、黑纱**替代传统麻布丧服；重孝（父、母）仍讲究「披麻戴孝」与守三年。
- 服丧期内子女**婚嫁、做客、行大礼**等从简，以「孝」为先；具体以家中长辈与宗族惯例为准。
- 与「守孝与周年」「七七百日」衔接：新亡期烧袱子（新逝显考/显妣）、做七、除服等，详见第八章。

### 7.5 如何判断是否在五服之内

> **核心口诀：同高祖为限，越高祖即出服。** 判断标准是**与逝者最近的共同祖先**落在哪一代。

**判断步骤：**

1. **找共同祖先**：把自己与逝者分别往上追溯历代祖先，找到两人**最近的一个共同祖先（共祖）**。
2. **数世代（辈数）**：从这位共祖往下，数到「自己」这一代经过了几代（即共祖与自己是第几世）。
3. **对照范围**：
   - 共祖**不高于「高祖」**（即共祖是自己上溯第四代及以内）→ **在五服之内（有服）**。
   - 共祖**比高祖还高**（已是高祖以上、远祖）→ **出五服（无服）**，不必服丧。

**旁系（同姓族亲）对照表：**

| 最近共同祖先（共祖） | 与逝者关系     | 服等  |
| ---------- | --------- | --- |
| 父亲         | 兄弟（同胞）    | 齐衰  |
| 祖父         | 堂兄弟（同祖）   | 大功  |
| 曾祖         | 再从兄弟（同曾祖） | 小功  |
| 高祖         | 族兄弟（同高祖）  | 缌麻  |
| 高祖以上（远祖）   | 出五服       | 无服  |

**直系（上下数代）：**

- **上推**（长辈）：父（斩衰）→ 祖（齐衰）→ 曾祖（齐衰五月）→ 高祖（齐衰三月）→ 高祖以上（出服）。
- **下推**（晚辈）：子（斩衰）→ 孙（齐衰）→ 曾孙、玄孙（有服，渐轻）。

**易混点：**

- **辈分差不影响「是否在服」，只影响「服等」**：即便与逝者辈分差很多，只要共祖在高祖以内就有服，只是服等（轻重、期限）不同。
- **出嫁女性**：在室（未婚）按本宗服；出嫁后以**夫家本宗**为主（「出嫁从夫」），对娘家多降等或出服，需按宗族惯例。
- **过继、随母姓、异性收养**等会影响宗族归属，属「大宗小宗」制度，需查族谱与宗族惯例。

**实际做法（本地）：**

- 最可靠：**查族谱／宗谱世系**，看与逝者同出哪一世祖；或直接问家中长辈、族长（「本家」）。
- 民间以「**出五服**」即不必通丧设灵；「**本家五服**」内则丧事必到、照章执丧。

## 八、守孝与周年制度

### 8.1 守孝

- 传统**守孝三年**（实为二十七月，多从简，对应五服之斩衰）；期间孝子不剃头、不婚嫁、不赴宴（旧俗，现代多从简）。
- 丧服（五服，见第七章）决定守孝轻重，长辈对晚辈、晚辈对长辈各有规制。

### 8.2 七七与百日

| 阶段    | 说明                        |
| ----- | ------------------------- |
| 头七    | 死后第七天，设灵祭奠                |
| 二七至七七 | 每七日设祭（「做七」），七七（断七/满七）较为隆重 |
| 百日    | 满百天卒哭，烧纸除哭                |

- 新亡期间烧袱子（「**今当新亡之期**」，七七 / 百日），见烧袱子指南 4.5 节。

### 8.3 周年与除服

| 时间    | 期语称呼（见烧袱子指南 4.6 节） |
| ----- | ------------------ |
| 死后满一年 | 小样之期（亦作小祥）         |
| 死后满两年 | 大样之期（亦作大祥）         |
| 死后满三年 | 除服之期               |

- 三年后称「**故显考 / 故显妣**」，三年内称「**新逝显考 / 新逝显妣**」。

## 九、上坟与扫墓

### 9.1 时机

- **祭扫**：清明（扫墓挂青）、春节（拜年上坟）、七月半、寒衣节、忌日、新亡百日周年。
- **打扫坟 / 动坟土**：本地多在**大寒至立春之间**才打扫坟、培土、动坟土；其它时节一般忌讳动坟土（见 9.3）。
- **新坟（三年内）**：新坟三年内一般**不能扫坟、垒土**，满三年方可（见 9.3）。

### 9.2 仪式

1. 除杂草、培土、修整坟头。
2. 挂青 / 压纸（坟头挂白纸、彩纸、压纸钱）。
3. 上香点烛、摆供（刀头、酒、水果）——上香、跪拜详见第五章。
4. 烧纸 / 烧袱子（见烧袱子指南）。
5. 祭拜（作揖、跪叩），口念请祖先"享用""保佑"。
6. 撒酒（奠酒），收供。

### 9.3 本地特点

- 清明上坟重在「**挂青**」，坟头挂纸多寡象征后人香火。
- 上坟**忌**踩他人坟头、忌不敬、忌在坟前嬉闹。
- **时令禁忌**：本地一般都在**大寒与立春之间**才**打扫坟**（除草、培土、修整坟头）、**动坟土**；其它时节一般忌讳动坟土。**动土修房造屋**（破土、立基、修房）也多选在**大寒至立春**这段农闲时令，寓意「开春动土、顺风顺水」。
- **新坟三年**：本地新坟（亡后三年内）一般**不能扫坟、垒土**，满了**三年**才能扫坟垒土；新坟三年内上坟以**祭拜、挂纸、烧纸（烧袱子）**为主，**不动坟土**。满三年后按常例扫坟、培土、垒土（详见《平昌岁时传统节日民俗》清明「新坟不过社」）。

## 十一、丧仪中的遗俗与禁忌

> 供参考，以当地长辈与家族惯例为准。

- **红事避白事**：家有丧事（尤其是新亡未满），不宜短期内办喜事。
- **喜丧**：高龄长寿者去世称「喜丧」，较丧事淡化悲哀、近喜庆（部分地方）。
- 出殡**不走回头路**，途中不回头张望。
- 灵前**灯不灭**（长明灯），守灵时莫灭灯。
- 丧期**不剃头、不洗脸刮胡**（重孝），以示哀痛（旧俗）。
- 未满十二岁儿童、孕妇，部分家庭习俗不强求参与丧仪。
- 烧纸**忌用红笔**写包袱、忌直书亡者名讳不避讳（见烧袱子指南第八章）。
- 墓地**忌**乱动他人祖坟、忌砍伐坟地风水树；**动坟土、动土营造**忌在**大寒至立春之外**的时节进行（见第九章、第十章）。
- **新坟三年**：新坟三年内**忌扫坟、垒土、动坟土**，一般只祭拜烧纸；满三年方可扫坟垒土（见第九章）。

## 十二、烧袱子要点引用

> 烧袱子是平昌七月半及多个节令的核心祭祀形式，具体封面**竖排十列**写法、「**男讳女不讳**」规则、称谓对照表（考/妣、显/先、公/母）、常用范文模板一至十、以及各节令**期语称呼**，均详见《平昌七月半烧袱子书写指南》v1.0.0。

**要点速记：**

- 单人包**十列**（右起→左），双人合包**十一列**（模板十）。
- 收者列（故显考/故显妣……）**字最大、顶格**；第一列空两格、第二列空四格。
- 男性亡者第五列写「**讳**」；女性亡者第五列写「**宅**」（男讳女不讳）。
- 收者尊称：男「**老大人**」、女「**老孺人**」。
- 三年内「**新逝显考/显妣**」，三年后「**故显考/故显妣**」。
- 期语用「**今当〈称呼〉之期**」，日期用「**公元××××年农历×月×日 坟前化帛**」。

# 第三卷 · 四川平昌红白喜事礼俗 v1.0.0

> 适用地区：四川省巴中市平昌县及周边川东北地区
> 主题：婚嫁、生育、寿诞、乔迁等喜庆礼俗（红事），及白事人情往来（香仪/随礼）
> 版本：**v1.0.0**
> 说明：**白事**（丧葬全程礼仪、守孝、周年）详见《平昌祭祀与丧葬礼俗》v1.0.0；本文侧重**红事**礼序与人情往来，并与丧葬篇交叉引用。

---

## 一、概述

平昌民间把**婚礼、寿诞、生育、乔迁**等喜庆称作「**红事**」，把**丧事**称作「**白事**」，合称「**红白喜事**」。本地重「**人情**」，礼尚往来是邻里、亲属维系关系的核心；红白喜事皆讲究**择吉日、请亲戚、设宴款待、随礼往来**。

> 本地口传：川东北有「**红事请，白事到**」之说——红事（婚礼、寿宴等）须主人**发请柬/相邀**才去；白事则亲友**主动上门**吊唁帮忙。各地细节以当地长辈和家族惯例为准。

---

## 二、婚嫁礼俗（红事）

### 2.1 流程总览

| 阶段        | 说明               |
| --------- | ---------------- |
| 提亲 / 说媒   | 由媒人牵线，两家议亲       |
| 合八字 / 看日子 | 请人合八字，择定婚期（良辰吉日） |
| 定亲 / 订婚   | 下聘、交换庚帖，两家确定婚事   |
| 过礼 / 送彩礼  | 男方送彩礼（聘礼），女方回礼   |
| 迎亲        | 新郎带迎亲队伍至女方家接亲    |
| 拜堂        | 拜天地、拜高堂、夫妻对拜     |
| 闹新房       | 亲友闹洞房，增添喜庆       |
| 回门 / 谢媒   | 三朝回门，婚后谢媒、走亲戚    |

### 2.2 本地特色

- **接亲车队/队伍**：川东北婚庆近年多用车队，农村有些保留抬花轿、举伞等旧俗。
- **哭嫁 / 骂媒**：部分地方有「哭嫁」旧俗（新娘哭诉离别），现已少见，以当地口传为准。
- **讨红包**（接亲时）：迎亲队伍进门，女方亲友讨「红包」「开门礼」，增添喜庆。
- **闹新房**：亲友闹洞房，以「越闹越热闹」为吉。
- **三日回门**：婚后第三天（或选日）新娘新郎回娘家「回门」，答谢父母养育。

### 2.3 婚宴与随礼

- 婚宴设「**喜宴**」，宴请亲友；多用**红色**（喜气）。
- 亲友随礼（**贺仪**），写礼金封皮（见第七章「贺仪」）。

---

## 三、生育礼俗（三朝 / 满月 / 周岁）

### 3.1 三朝 / 打三朝

- **时间**：婴儿出生后第三天（三朝），举行「三朝礼」。
- **习俗**：
  - **洗三**：给婴儿洗澡（洗三朝），寓意洗去秽气、祝健康。
  - **报喜**：向亲友报喜。
  - 男孩称「**弄璋之喜**」、女孩称「**弄瓦之喜**」（见烧袱子指南 4.6 节「弄璋之期 / 弄瓦之期」）。
- **送礼**：亲友送鸡蛋、红糖、衣物等（「**贺生**」）。

### 3.2 满月

- **满月酒**：婴儿满月办酒席宴请亲友（「满月宴」）。
- 亲友送**长命锁、银饰、红包**等；外婆家送衣物、银饰（「**送满月**」）。

### 3.3 周岁（抓周）

- **周岁宴**：办周岁酒，举行「**抓周**」——摆书、笔、算盘、钱、玩具等，任婴儿抓取，预测将来志向（民间趣味，理性看待）。

---

## 四、寿诞礼俗

| 对象      | 称呼  | 说明               |
| ------- | --- | ---------------- |
| 长辈寿辰    | 做寿  | 逢整十（六十、七十、八十）重大寿 |
| 满月 / 周岁 | 生日  | 见第三章             |
| 高寿      | 敬老  | 近年重「敬老」          |

- **做寿**：设寿宴，亲友祝寿送礼（**寿敬**，见第七章）；点寿烛、吃寿面（长寿面）、寿桃。
- **本地注**：川东北做寿**六十为大寿**，送「寿敬」礼金；丧事送礼称「香仪」（见第六章）。

---

## 五、乔迁与建房礼俗

| 事项       | 说明                                             |
| -------- | ---------------------------------------------- |
| 上梁       | 建房架梁，择吉「**上梁**」，请匠人，亲友帮忙，挂红、放炮（「**竣工**」「竖造」之期） |
| 乔迁（进新房）  | 择吉搬迁，设「**乔迁宴**」，亲友送礼（「**乔迁**」/「菲仪」）            |
| 敬土地 / 安宅 | 迁居前后敬土地神、安宅（见《平昌祭祀与丧葬礼俗》「家宅神祇」）                |

- 乔迁宴多用红色，寓意「**乔迁之喜**」；送礼封皮写「**乔迁**」或「**菲仪**」（见第七章）。

---

## 六、白事人情往来（香仪 / 随礼）

> 白事全程礼仪详见《平昌祭祀与丧葬礼俗》v1.0.0。本节侧重**人情往来**。

- **主动到场**：白事亲友**主动上门**吊唁、帮忙（川东北「白事到」），无需请柬。
- **送礼（香仪 / 冥仪）**：亲友送「**香仪**」（丧事礼金，也叫「人情」「奠仪」），封皮写「**香仪**」。
- **随礼数额**：礼金多寡视亲疏与家境，川东北多以「回礼」方式体现人情（主家回赠，如回礼布、回礼钱）。
- **吊唁**：送花圈、挽联、孝帕；拜灵、上香、鞠躬（或跪拜）。

> 烧袱子 / 化纸涉及的**期语**（除灵、葬期、忌日、周年等）及**随礼称呼**（香仪、贺仪、寿敬、乔迁等）见《平昌七月半烧袱子书写指南》4.6 节「送礼仪语」。

---

## 七、礼金封皮与随礼称呼

> 送礼时礼金封皮（信封/红包）常用红色（红事）或白色（白事），其上书写随礼称呼。以下称呼与烧袱子指南 4.6 节「送礼仪语」一致。

| 场合    | 封皮称呼           | 备注  |
| ----- | -------------- | --- |
| 送男方结婚 | 贺仪             | 红事  |
| 送女方出阁 | 奁仪             | 红事  |
| 祝寿送礼  | 寿敬             | 红事  |
| 建房迁居  | 乔迁（或菲仪）        | 红事  |
| 饯行送礼  | 展翅（或文仪）        | 红事  |
| 丧事送礼  | 香仪             | 白事  |
| 生育送礼  | 贺生（或弄璋 / 弄瓦之仪） | 红事  |

> 随礼与礼节因亲疏、家境而异，以当地习惯与主家约定为准。

---

## 八、红白喜事禁忌与讲究

> 川东北民间传统说法，供参考；现代家庭不必过度拘泥。

- **红事请、白事到**：红事邀约，白事主动（见第一章）。
- **丧期避喜**：家有新亡，短期内不宜办红事；喜事、白事宜错开。
- **红色 / 白色**：红事用红色（喜气），白事用白色（哀思），不宜混用。
- **红事忌带孝**：家有孝服（守孝）者，部分人家避参加红事（旧俗）。
- **吉日选择**：婚、寿、乔迁多择「**吉日**」（请人看日子），避开「杨公忌日」等不吉之日（各地不一）。
- **白事帮忙重「孝」**：帮忙者、亲友丧期行为从容得体，忌嬉闹（喜丧例外）。

# 第四卷（附录） · 四川平昌地区「烧袱子」书写指南 v1.0.0（七月半 · 中元节）

> 适用地区：四川省巴中市平昌县及周边川东北地区
> 适用时节：农历七月（七月半 / 月半节 / 中元节）
> 2026 年（丙午年）农历七月十五 = 公历 2026 年 8 月 27 日
> 版本：**v1.0.0**

---

## 一、习俗背景

**七月半**，即农历七月十五**中元节**，民间又称"鬼节""月半节"。传说农历七月初一"鬼门开"，地府鬼魂回阳间探亲，至七月十五"鬼门关"，故七月是民间祭祖的重要月份。

在平昌及整个巴中、川东北地区，七月半祭祖的核心形式就是**烧袱子**（也称"烧包""烧包袱""写包袱"）。所谓"袱子"，就是用纸折成信封状的纸包，里面装入纸钱（冥币、金银纸锭），**封面上用毛笔竖写亡人的称谓、名讳、财帛数量、日期和化帛人**，然后焚烧，寓意给阴间的祖先"寄钱寄物"。

> 平昌本地老一辈有说法："七月半，鬼门开，十三烧袱子。"川东北不少家庭习惯在七月十三或十四傍晚焚烧，也有在十五正日烧的，各家各院略有差异，以自家长辈口传为准。

---

## 二、时间安排（2026 丙午年）

| 农历   | 公历（2026 年）   | 事项                           |
| ---- | ------------ | ---------------------------- |
| 七月初一 | 8 月 13 日（周四） | 鬼门开，七月祭祖开始                   |
| 七月十二 | 8 月 24 日（周一） | **接亡人**：傍晚堂屋摆供、点香烛、烧散纸，请祖先回家 |
| 七月十三 | 8 月 25 日（周二） | **烧袱子**（平昌一带多数家庭选此日或次日）      |
| 七月十四 | 8 月 26 日（周三） | **烧袱子**（部分家庭，参考范本即写此日）       |
| 七月十五 | 8 月 27 日（周四） | 中元节正日，**送亡人**：再烧纸钱、泼水饭，送祖先归去 |

**说明：**

- 包袱一般**提前写好**，十三、十四下午至黄昏（太阳落山前后）焚烧，讲究"天黑前烧完"。
- 若遇雨天，可提前至十二、延后至十五，不在夜里十点后焚烧。
- 新亡（三年内）之家，有的地方规矩不同，请先问家中长辈。

## 四、包袱封面的书写格式（核心）

### 4.1 整体版式（平昌本地十列写法）

平昌本地包袱封面为**竖排书写，自右向左共十列**（右起第一列 → 第十列），各列起笔高度有讲究。书写时把纸包正面朝上、封口朝上，用毛笔自上而下、自右而左书写。以下为按参考范本整理的标准版式：

```
右起第一列：今当中元之期　　　　　　　　　　　　（起笔空两格）
右起第二列：虔具冥财〈大写数字〉封　　　　　　　（起笔空四格）
右起第三列：奉　　　　　　　　　　　　　　　　　（字居底部）
右起第四列：上　　　　　　　　　　　　　　　　　（顶格）
右起第五列：讳　　　　　　　　　　　　　　　　　（与第六列"公"后的空格齐平，即与名字同位）
右起第六列：故显考〈姓〉公　〈名〉老大人一位正魂收用（顶格，字最大）
右起第七列：男　〈祭祀人夫姓名〉　　　　　　　　（比第八列低一格）
右起第八列：孝　跪叩　　　　　　　　　　　　　　（与第六列"老"字齐平）
右起第九列：媳　〈祭祀人妻姓名〉　　　　　　　　（比第八列低一格）
右起第十列：公元二零二六年农历七月十四日　坟前化帛（起笔空两格）
```

| 右起列序 | 书写内容                 | 起笔位置                |
| ---- | -------------------- | ------------------- |
| 第一列  | 今当中元之期               | 顶部空两格               |
| 第二列  | 虔具冥财〈大写数字〉封（壹、贰……）   | 顶部空四格               |
| 第三列  | 奉                    | 字居底部                |
| 第四列  | 上                    | 顶格                  |
| 第五列  | 讳                    | 与第六列"公"后空格齐平（与名字同位） |
| 第六列  | 故显考〈姓〉公 〈名〉老大人一位正魂收用 | 顶格，**字最大**          |
| 第七列  | 男 〈祭祀人夫姓名〉           | 比第八列低一格             |
| 第八列  | 孝 跪叩                 | 与第六列"老"字齐平          |
| 第九列  | 媳 〈祭祀人妻姓名〉           | 比第八列低一格             |
| 第十列  | 公元××××年农历七月××日 坟前化帛  | 顶部空两格               |

**关键位置关系（依参考范本）：**

- 第一列空两格、第二列空四格、第十列空两格起笔。
- 第四列"上"顶格、第三列"奉"居底部，两列合读为"**上奉**"。
- 第五列"讳"与第六列"公"字后的空格齐平（与名字同一高度）；名字写在第六列"公"后的空格处。
- 第六列顶格，为全包字最大的一列。
- 第八列"孝 跪叩"与第六列"老大人"的"老"字齐平；第七列"男××"比第八列低一格；第九列"媳××"比第八列低一格。

**女性亡者（如母亲、祖母）的差异写法：**

```
右起第五列：宅（与第六列名字同位；男性写"讳"，女性写"宅"）
右起第六列：故显妣〈逝者夫姓〉　〈逝者姓名〉老孺人一位正魂收用（顶格，字最大）
```

- 女性包袱**第五列**由"讳"改为"**宅**"字，"宅"指其内宅故居，为对女性亡者的敬称。
- 女性包袱**第六列**写"**故显妣〈逝者夫姓〉　〈逝者姓名〉老孺人一位正魂收用**"，夫姓在前、逝者本人姓名在后（如"故显妣王　秀英老孺人一位正魂收用"）。
- 其余各列（奉送语、上奉、化帛人、日期落款）与男性写法相同。

### 4.2 十列内容说明

对照 4.1 版式，各列作用如下：

1. **第一、二列——奉送语与财帛**：第一列写"今当中元之期"（奉送语）；第二列写"虔具冥财〈大写数字〉封"（如"虔具冥财壹封"），用大写数字注明封数或包数。
2. **第三、四列——上奉**：第四列顶格写"上"，第三列底部写"奉"，合读为"上奉"，表示恭敬奉上。
3. **第五列——讳 / 宅**：单列一字，与第六列名字同位。男性亡者写"**讳**"（敬避名讳）；女性亡者写"**宅**"（指内宅故居，女性敬称）。名字写在第六列"公"（男性）或夫姓（女性）之后的空格处。
4. **第六列——收者（全包最重要）**：男性写"**故显考〈姓〉公 〈名〉老大人一位正魂收用**"（如"故显考张公 志强老大人一位正魂收用"）；女性写"**故显妣〈夫姓〉 〈逝者姓名〉老孺人一位正魂收用**"（如"故显妣王 秀英老孺人一位正魂收用"）。**字最大、顶格**。
5. **第七、八、九列——化帛人**：第八列写"孝 跪叩"（与第六列"老"字齐平），第七列写"男〈夫姓名〉"，第九列写"媳〈妻姓名〉"，分别比第八列低一格，表示儿孙媳辈跪叩奉送。
6. **第十列——日期落款**：写"公元××××年农历七月××日 坟前化帛"，注明焚烧日期与地点。

### 4.3 写法要点

- **称谓要准确**：考/妣、显/先、公/母等不能写错（见第五章对照表），写错等于送错人。
- **名讳要避讳**：男性亡者第五列写"讳"，女性亡者写"宅"，均与名字同位；名字只写名、不写姓（男性姓已含在"×公"中，女性以夫姓起首）。
- **用字讲究**：父母辈用"显考 / 显妣"，祖辈以上用"祖考 / 祖妣、曾祖考 / 曾祖妣、高祖考 / 高祖妣"；若亡者去世时其父辈仍健在（或家族中有更长辈），则用"先考 / 先妣"以示谦抑。
- **尊称**：男性亡者称"老大人"，女性亡者称"老孺人"（或"老安人"）。
- **字迹工整**：忌潦草、忌错别字、忌涂改；写错请重写一张，不可划掉。
- **颜色**：一律用黑墨，**忌用红笔**。
- **封口**：包好纸钱、写完后用浆糊封口，封口处可再贴一条"封条"。

**称谓常识：**

- **考**＝已故的父亲，**妣**＝已故的母亲；"故考 / 故妣"即"已故的父亲 / 母亲"。
- **显**＝有德望、受尊敬（多用于父母、祖辈）；**先**＝通用谦称（父辈先亡时用"先考"更合礼数）。
- **讳 / 宅**：第五列单列一字，与第六列名字同位。男性亡者写"**讳**"（敬避名讳），女性亡者写"**宅**"（指内宅故居，女性敬称）。
- **老大人 / 老孺人**＝对亡故男女长辈的尊称。
- **一位正魂收用**＝平昌本地常用收语（指亡者本人魂魄收受）；平辈、晚辈也可简写"收"。
- 夫妻亡者可写**合包**（一封包两人），按模板十的十一列交错版式书写（男讳女不讳）；也可各写一封。

**祭祀人（化帛人）自己的称呼写法：**

## 六、常用范文模板

> 使用说明：模板中"〈〉"按实际替换；**模板一为完整十列示范**，其余模板只列出需替换的列，未列出的列照抄模板一；**双人合包为十一列，见模板十**。所有模板按 4.1 节版式竖排、自右向左书写，收者列字最大、顶格；日期按实际焚烧日填写。

## 七、焚烧礼仪与步骤

1. **接祖（七月十二前后）**：傍晚在堂屋或院坝摆供桌，点香烛，烧几张散钱纸，口念"祖先回家过节"，此后每日三餐前上香。
2. **打纸钱**：用钱凿在草纸上打铜钱印；装入包袱封好、写好封面。
3. **画圈**：在院坝空地上用草木灰画一个圈，**圈口朝向祖坟方向**（或传统所指的西北方向），圈内烧自家包袱。
4. **先烧特殊封**：先在**圈外**烧"地盘业主""车夫力士"包，再在**圈内**按辈分从高到低烧自家包袱。
5. **逐一焚烧**：每烧一封念诵，如"××公（称呼），七月半了，给您送钱来了，请收好，在那边吃饱穿暖，保佑子孙平安。"
6. **烧透烧尽**：用长棍轻轻挑开，确保烧透；**中途不翻搅过猛**，民间认为会惊扰亡人收钱。
7. **送祖（七月十五）**：正日傍晚再烧一批纸钱，泼一碗"水饭"（清水泡冷饭）送祖先归去，撤供。
8. **收尾**：待火完全熄灭、灰烬冷却后再离开；灰烬按当地习惯倒入河沟或埋入土中，不混入生活垃圾。

## 八、禁忌与民俗讲究

> 以下为平昌本地及川东北民间传统说法，供参考；现代家庭不必过度拘泥，以心诚为主。

- **忌红笔**书写包袱，对亡人不敬。
- 亡人**名讳不可写错**、不可直书其名不避讳。
- 写错或写坏的字纸**不可乱丢**，宜随包袱一并焚化。
- 焚烧时**不宜大声呼喊活人全名**，以免惊扰。
- 未满十二岁儿童、孕妇，部分家庭习俗不参与焚烧。
- 不拾取、不踩踏他人焚烧的纸灰与包袱。
- 圈内钱**不可用木棍乱捅**、不可烧一半取走。
- 七月半前后夜晚传统讲究：不晾晒衣物过夜、不吹口哨、不在野外逗留太晚（民间传说，理性看待）。
- 新亡未满三年之家，部分地方有"新坟三年不过七月半"或提前烧的讲究，**以家中长辈说法为准**。

## 九、文明祭祀与安全提示

- 平昌县城及乡镇近年倡导**文明祭祀**，城区设有集中焚烧点，请先在社区 / 物业确认可焚烧地点。
- **严禁**在林地、草丛、秸秆堆、燃气管道附近焚烧；烧完确认**火种完全熄灭**再离开，人走火灭。
- 提倡**鲜花祭祀、电子香烛、网上祭扫**等绿色方式；焚烧时减少塑料冥币（燃烧产生有害气体）。
- 购买纸钱请选正规渠道，注意防火包装，焚化后清理现场。
