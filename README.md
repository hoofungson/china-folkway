# 四川平昌县地方民俗知识体系

> 适用地区：四川省巴中市平昌县及周边川东北地区
> 主题：传统节日 / 祭祀与丧葬 / 红白喜事 / 烧袱子书写

本仓库系统整理**平昌县地方民间民俗**知识，采用**分主题 + 满十进位版本管理**的方式组织，并给出可直接分享、打印的**合订本 PDF**（含书签）。

内容整理自平昌、巴中及川东北民间口传习俗与公开资料，**各地细节以当地长辈和家族惯例为准**。

## 版本管理规则

1. **版本号格式**：`v〈主版本号〉.〈次版本号〉.〈修订号〉`，三段均为阿拉伯数字。
2. **满十进位**：
   - 修订号满十 → 进位至次版本号，修订号归零：`v1.0.9 → v1.1.0`。
   - 次版本号满十 → 进位至主版本号，次版本号归零：`v1.9.9 → v2.0.0`。
   - **数字不出现 10**，不存在 `v1.0.10`。
3. **版本号含义**：主版本＝主题范围重大调整；次版本＝新增章节/内容扩充；修订号＝文字/日期订正、小幅润色。
4. **命名约定**：`主题名-v〈主版本号〉.〈次版本号〉.〈修订号〉.md`。
5. **历史保留**：生成新版**不覆盖、不删除**旧版；同一主题多版本并存，最新版以版本号最大者为准。
6. 各篇文末有「版本历史 / 版本说明」记录当前版本与规则。

## 如何使用

- **速览**：先看《平昌民俗知识体系总览》对应主题与版本；或直接打开合订本。
- **合订本（Markdown）**：四卷汇编，卷首有可点击总目录（锚点 `#vol1`–`#vol4`），便于编辑器内跳转。
- **合订本（PDF）**：[`PDF导出\平昌民俗知识合订本-v1.4.0-含书签.pdf`](./PDF导出/平昌民俗知识合订本-v1.4.0-含书签.pdf)，含**两级书签**（7 个一级章节 + 各卷二级小节），中文正常（UTF-16BE 编码），可直接分享、打印、发给长辈。

### 重新导出自带书签的 PDF（当合订本更新后）

1. 用 Markdown→HTML 转换器生成 HTML（支持中文、表格、代码块）。
2. 用无头 Chrome `--headless=new --no-sandbox --print-to-pdf` 打印为 PDF（需放宽沙箱访问权限，见下）。
3. 用 `pdf-lib` 追加书签（`PDFHexString.fromText` 编码标题避免中文乱码）。

> 注：本仓库所在环境（受限沙箱）下，Chrome 打印需 `danger-full-access` 权限；相关辅助脚本在生成后即清理。

## 编写约定（各主题文档）

- **标题**：含主题与版本号，如 `# 四川平昌岁时传统节日民俗 v1.6.0`。
- **头信息**（引用块）：适用地区、适用时节/对象、版本号。
- **目录**：便于跳转。
- **正文**：以表格、要点、范例呈现，突出平昌本地特色；本地口传处标注「以当地长辈口传为准」。
- **交叉引用**：主题间互相引用（如烧袱子细则→《平昌七月半烧袱子书写指南》）。
- **版本历史 / 版本说明**：文末记录版本号与满十进位规则。

## 维护提示

- 各篇版本号会随本地细节补充而升级（内容扩充→次版本号；订正→修订号）。
- **注意清理非版本链的乱码孤儿文件**：本环境偶尔会出现「版本窜号 + 内容乱码」的异常文件（如曾出现的 `-v1.2.1/-v1.2.2/-v1.2.3`），它们不属于正常「满十进位」链，建议删除并检查是否有外部自动同步进程。
